# 日本人の県外移動アニメーション（`takedayasushi/japanese_move`）

『統計で読む日本』特別編：総務省統計局の実測値だけを使い、都道府県間の人口移動を年齢（5歳階級）別にアニメーションで見る静的Webページです。補間はしていません。

## 使い方

- 年齢スライダー（0〜4歳〜85歳以上）で年代を切り替え、再生ボタンで年齢を順に送れます。
- 都道府県（タイル／地理地図）をクリックすると、転入元・転出先トップ5、国外からの転入・国外への転出、5年前の常住地構成を表示します。
- 「海外」ノードは48番目のノードとして統合されています（国外からの転入・国外への転出は全年代合計のみ公表のため、年齢別の内訳はありません）。
- 地理地図／タイル地図の切り替えができます。

## データ生成

`build_migration_data.py` は e-Stat のファイルダウンロード（APIキー不要）で Excel 原表を取得し、`data/migration.json` を生成します。

```bash
python3 build_migration_data.py --year 2024 --out data/migration.json
```

Python 3.10+ と openpyxl が必要です（`pip install openpyxl`）。

### 使用した一次データ（すべて総務省統計局・e-Stat）

対象年次は 2024年（年報、2025-01-31公表）です。

| 内容 | 統計・表 |
|---|---|
| 年齢（5歳階級）別・都道府県間転入数 | 住民基本台帳人口移動報告 年報（実数）2024年 表3-1 |
| 年齢（5歳階級）別・都道府県間転出数 | 同 表3-2 |
| 年齢（5歳階級）別・転入超過数 | 同 表3-3 |
| 移動前の住所地別転入者数（出身都道府県×年齢） | 同 表8-1 |
| 移動後の住所地別転出者数（転出先都道府県×年齢） | 同 表8-2 |
| 国外からの転入者数・国外への転出者数（全年代合計） | 同 表80 |
| 5年前の常住都道府県別人口（2020年国勢調査 第6表） | 国勢調査 2020年 移動人口の男女・年齢等集計 第6表 |

※ 国勢調査は出生地別人口を都道府県別に公表していないため、出生地構成パネルの代わりに「5年前の常住地構成」（2020年国勢調査 第6表）を表示しています。ページ内にもその旨を注記しています。

### 検算（スクリプトが自動で実施し、全項目パス）

- 転入超過数 ＝ 転入数 − 転出数（47都道府県×18年齢階級）
- 転入超過数の全国合計 ＝ 0（年齢階級ごと）
- 表8-1の都道府県間移動合計 ＝ 表8-2の合計 ＝ 表3-1の全国合計（年齢階級ごと）
- 表8-1と表8-2の移動フローが一致（同一の都道府県ペア・同一数値）
- 5年前の常住地構成の内訳合計 ＝ 総数（都道府県ごと）

2024年の都道府県間移動者数（年齢階級別合計）は 2,523,239人で、公表の総数 2,523,249人と10人異なります（年齢階級表に含まれない10人分）。JSON は年齢階級別の値を使い、ページの注記にこの差を明記しています。

## 公開手順（GitHub Pages）

1. GitHub に公開リポジトリ `takedayasushi/japanese_move` を作成します。
2. `index.html`、`data/migration.json`、`data/japan.topojson`、`build_migration_data.py`、この README を push します（`source/` の Excel 原表は含めません）。
3. GitHub の Settings > Pages で `main` ブランチを公開に設定します。

## 注記

- 数値はすべて実測値で、補間はしていません。滑らかさは 0.8秒の視覚遷移だけで作っています。
- 85歳以上は 85〜89歳と90歳以上の合計です。
- 5年前の常住地構成には「移動状況『不詳』」が多く含まれます（東京都 24.8% など）。不詳も含めてそのまま表示しています。
